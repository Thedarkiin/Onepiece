# Sail the Ocean — One Piece 3D Experience

⚓ **Live Website:** [Click here to experience the project](https://thedarkiin.github.io/Onepiece/)

A pure, immersive 3D sailing experience built with Three.js, React (Vite), and custom WebGL shaders. Sail the iconic *Going Merry* across an endless ocean featuring a dynamic day/night cycle, a flying dragon, and an atmospheric soundtrack.

## 🎮 Controls

- **W / Up Arrow**: Accelerate Forward
- **S / Down Arrow**: Reverse
- **A & D / Left & Right Arrows**: Steer Ship
- **Click & Drag**: Orbit Camera

## ✨ Features

- **Interactive Sailing:** Physics-based steering with momentum, water drag, and collision detection.
- **Cinematic Orbit Camera:** SmoothOrbit controls restricted to above-water panning.
- **Dynamic Cycle:** Switch between a warm, realistic "golden hour" sunset and a thunderstorm night featuring custom lightning flashes and changing audio tracks.
- **PBR Environment:** Utilizing Three.js official `Water` and `Sky` addons for realistic sun scattering and ocean reflections.

## 🚀 Running Locally

```bash
npm install
npm run dev
```
